Pi 0–10 V Output

An isolated 0–10 V control output for a Raspberry Pi. Relay K1 selects between a fixed 10k/10k divider (default) and a PWM-driven DAC module, and only the selected source is powered.

Build notes

  • Set the PWM duty before driving GPIO23 high. U2 powers up cold on every switchover; the GP8101 needs up to 10 PWM cycles to lock on, so allow about 100 ms.
  • R4/R8 keep the GP8101 PWM input within its 3.0–5.5 V logic-high range. Never feed it the full 12 V.
  • The low-power values (R1 680 Ω, R4/R8 10k/5.1k) slow the optocoupler edges slightly. Calibrate the offset in software, and fit R5 only if the scope shows slow falling edges.
  • Use hardware PWM on GPIO18. Software PWM jitter shows up as noise on the output.
  • Check that U2's inrush current is within K1's switching rating.
